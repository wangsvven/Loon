## 地质剖面图生成工具 (Geological Profile Generator)

本项目新增了一个Python工具，用于生成地质剖面简图。

### 快速开始

```bash
# 安装依赖
pip install -r requirements_geological.txt

# 快速入门（推荐新手）
python3 quickstart_geological.py

# 运行基础示例
python3 geological_profile.py

# 运行所有示例
python3 geological_profile_example.py
```

### 功能特点

- ✅ 支持多层地质结构可视化
- ✅ 中文宋体字体自动配置
- ✅ 自定义颜色和图表样式
- ✅ 输出高清PNG图片

### 相关文件

- `geological_profile.py` - 主程序模块
- `quickstart_geological.py` - 快速入门脚本（推荐新手）

- `test_geological_profile.py` - 功能测试套件
- `GEOLOGICAL_PROFILE_README.md` - 详细使用文档
